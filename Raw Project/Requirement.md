# REQUIREMENT

| Bagian | Keputusan |
|---|---|
| Teknologi | Laravel 12 + MySQL + Blade |
| Role | Admin & User/Karyawan |
| Booking | User mengajukan booking |
| Approval | Booking harus disetujui Admin |
| Ruangan | Menggunakan data dummy terlebih dahulu |
| Fasilitas | Dikelola Admin dan ditampilkan pada detail ruangan |
| Calendar | User dapat melihat ketersediaan seluruh ruangan |
| Availability | User dapat mencari ruangan berdasarkan tanggal, waktu, dan kapasitas |
| Double Booking | Sistem harus mencegah bentrokan jadwal |
| Notifikasi | Belum diperlukan |
| UI | Menggunakan desain Google Stitch sebagai referensi utama |
| Data perusahaan | Belum tersedia |
| Data awal | Menggunakan data dummy |
